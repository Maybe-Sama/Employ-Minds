# Changelog

All notable changes to Employ-Minds are documented here.

## 1.0.0 — 2026-08-12

### Added
- Single risk router with FAST, STANDARD, and CRITICAL profiles.
- Claude Code and Codex-style project integration without overwriting existing instructions.
- 13 composable engineering skills covering planning, TDD, debugging, execution, review, security, verification, context control, parallelism, research, and release discipline.
- 9 specialist agent roles with explicit handoff contracts.
- Idempotent cross-platform installer, partial uninstall support, first-install instruction backups, and project doctor.
- Multi-OS CI validation.
- Pinned upstream provenance and preserved MIT notices for ECC and Superpowers.
